# Estructura Base

Este folder alojara la implementacion web del cotizador de flexografia.

Propuesta inicial:

- `src/domain`
  - modelo y formulas de negocio
- `src/application`
  - casos de uso del cotizador
- `src/infrastructure`
  - persistencia, importacion de catalogos y adaptadores
- `src/web`
  - API y frontend

La implementacion real se ira agregando conforme validemos el comportamiento del sistema original.
